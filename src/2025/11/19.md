## 2. bool 值表示

bool 的值表示，就是存储的值是 0 1 还是其他，这是 ABI 定义的。例如 system v abi, itanium c++ abi 都规定了 false 用 0 表示，true 用 1 表示。

标准定义了 bool 只可能包含两个值 false true，以及 false true 转换为整数会变成 0 1。但是 false true 的表示没有规定。

***

这个说法是错误的：“bool 值表示是 0 和非 0，可以为 0..255 中间的任意值”。

```cpp
#include <bit>

bool foo(bool a, bool b) {
    return a == b;
}

// foo(bool, bool):
//         mov     eax, edi
//         xor     eax, esi
//         xor     al, 1
//         ret

bool bar(bool a)
{
    auto x = std::bit_cast<char>(a);
    return x == 0 || x == 1;
}

// bar(bool):
//         mov     al, 1
//         ret
```

上面例子用 clang 21.1.0 `-std=c++20 -O3` 编译，foo 编译成了 `(a ^ b ^ 1)` 说明了 bool 的值表示只能为 0 和 1；bar 更是直接返回了 1。

***

同时，严格来说标准是不保证 bool memset 为 0 的效果的，不过恰好所有实现都把全零当成 false，所以 memset 0 总是能用的。

## 3. reference_wrapper 相比于裸指针有啥优势

reference_wrapper 相比于引用应该大家都知道了，是可以拷贝、重新绑定。因此用于传参（比如 std::thread）是最大的使用场景。

相比于裸指针，reference_wrapper 保证非空勉强算一个优势。
