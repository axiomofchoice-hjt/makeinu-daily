## 1. 模板特化会“继承”主模版的存储期

```cpp
template <typename T>
static void foo();

template <>
static void foo<int>() {}  // error: explicit template specialization cannot have a storage class
```

特化的存储期都是跟主模板一样的，不重复写，都是直接“继承”主模板的。
