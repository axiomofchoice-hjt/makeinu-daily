## 1. 类里定义的成员函数编译后没有生成符号

```cpp
struct Test {
    void test() {}
};
```

因为类里定义的成员函数有 inline 效果，编译器可以不保留符号。

把成员函数拿外面定义就行了。

```cpp
struct Test {
    void test();
};

void Test::test() {}
```
