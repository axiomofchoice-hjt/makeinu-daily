## 1. GCC / clang 怎么关闭某个 warning

打开是 `-Wxxx`，对应的关闭是 `-Wno-xxx`。

## 2. 包展开规则

<https://zh.cppreference.com/w/cpp/language/pack> 里的“展开场所”列举了一系列语境，其中：

```cpp
f(g(args) + args...);  // 展开成 f(g(arg1) + args, g(arg2) + arg2, g(arg3) + arg3);
```

省略号写在一个实参的末尾，就把这个实参重复多次。

其他语境也类似。
