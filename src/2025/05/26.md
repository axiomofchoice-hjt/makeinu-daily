## 2. 函数指针可以内联吗

当然可以。

```cpp
void bar(int x) {
    asm volatile("nop");
}

template <class Func>
void foo(int x, Func func) {
    func(x);
}

void test() {
    foo(1, bar);
}
```

```text
bar(int):
        nop
        ret

test():
        nop
        ret
```
