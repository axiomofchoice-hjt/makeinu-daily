## 2. `unordered_map<string>` 不能查找 string_view

下面的代码会报错 `error: no matching function for call to 'xxx::find(std::string_view)'`。

```cpp
#include <iostream>
#include <string>
#include <unordered_map>

int main() {
    std::unordered_map<std::string, int> a;
    a.find(std::string_view());
}
```

虽然 <https://zh.cppreference.com/w/cpp/container/unordered_map/find> 在 C++20 之后支持了模板接口 `template< class K > const_iterator find( const K& x ) const;`，但是 Hash 和 KeyEqual 必须是透明的。

因此需要自定义哈希和比较运算：

```cpp
#include <iostream>
#include <string>
#include <unordered_map>

struct MyHash {
    using is_transparent = void;
    size_t operator()(const std::string& s) const {
        return std::hash<std::string>{}(s);
    }
    size_t operator()(std::string_view sv) const {
        return std::hash<std::string_view>{}(sv);
    }
};

struct MyEqual {
    using is_transparent = void;
    bool operator()(const std::string& a, const std::string& b) const {
        return a == b;
    }
    bool operator()(const std::string& a, std::string_view b) const {
        return a == b;
    }
    bool operator()(std::string_view a, const std::string& b) const {
        return a == b;
    }
};

int main() {
    std::unordered_map<std::string, int, MyHash, MyEqual> a;
    a.find(std::string_view());
}
```
