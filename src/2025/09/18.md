## 2. 函数参数 `T` 和 `T&&` 接收右值的优先级

```cpp
void foo(int a) {}
void foo(int &&a) {}

int main() {
    foo(1);
}
```

会报歧义，因为这两个在重载决议里都是完美匹配，优先级是一样的。
