## 1. 同名变量 shadow

```cpp
int x;
{
    int x;
}
```

shadow 容易出 bug。（且不能像 rust 那样初始化使用被 shadow 的变量，很鸡肋）

可以用编译选项 `-Wshadow` 警告这种行为。

这个是兼容 C 导致的。

[Why do programming languages allow shadowing/hiding of variables and functions?](https://softwareengineering.stackexchange.com/questions/215091/why-do-programming-languages-allow-shadowing-hiding-of-variables-and-functions)
