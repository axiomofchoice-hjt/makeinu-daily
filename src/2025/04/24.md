## 1. 下划线占位符进 C++26

<https://wg21.link/p2169>

```cpp
void foo() {
    int _ = 0;
    auto [_, x] = std::make_pair(1, 2);
}
```

这个功能一定程度上可以用宏代替：

```cpp
#define CONCAT(l, r) l##r
#define IGNORE(count) CONCAT(IGNORE_, count)
#define _ IGNORE(__COUNTER__)

void foo() {
    int _ = 0;
    auto [_, x] = std::make_pair(1, 2);
}
```
