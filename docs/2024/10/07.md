## 1. 面试题：字节对齐

```cpp
struct A {
    char a[20];
    virtual void f() {}
};
```

问 `sizeof(A)` 是多少？

只考虑 64 位程序，答案是 32。

一般来说按顺序是：8 字节的虚指针，20 字节的 char 数组，4 字节对齐。

（但是标准并没有规定虚指针在开头，这是实现定义的）
