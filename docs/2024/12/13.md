## 1. 怎么安全的边遍历边删除 map

用迭代器，`map::erase` 返回删除元素的后一个，所以这么写：`it = map.erase(it)`

```cpp
for (auto it = map.begin(); it != map.end();) {
    if (...) {
        it = map.erase(it);
    } else {
        ++it;
    }
}
```

## 2. 带初始化语句的 range base for (C++20)

```cpp
for (int i = 0; auto [key, value] : map) { ... }
```

类似的，if 也可以定义 (C++17)。

for 循环的初始化语句还可以写别名声明 (using) (C++23)。
