## 2. hidden friend 只能通过 ADL 找到

```cpp
struct X {
    friend int sum(X a, X b) { return a.x + b.x; }
    void foo() { sum(*this, *this); }
    void bar() { sum; }  // error

    int x;
};
```

标题就是原因。

可以把 sum 改为静态成员函数，或者 sum 的定义放外面变成普通函数。

hidden friend 的意义是强制 ADL，比如重载 `<`。
