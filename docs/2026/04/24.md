## 3. std::priority_queue 没有 reserve 接口

小寄巧，可以继承 std::priority_queue，然后访问 protected 成员变量 c 拿到容器。[cppref](https://zh.cppreference.com/cpp/container/priority_queue) 里搜“成员对象”。

```cpp
struct priority_queue : public std::priority_queue<int> {
    void reserve(int64_t n) { c.reserve(n); }
};
```
