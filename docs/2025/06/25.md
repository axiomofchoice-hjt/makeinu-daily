## 1. C++26 的反射什么时候能用

据说 GCC 下个大版本可以用。

Clang 有设计缺陷，目前的架构不允许一边实例化模板一边进行常量求值，要重构 / 重写，工作量巨大。

MSVC 特性已经落后了。

## 2. 团队合作用公共分支还是 PR

看情况选择。公共分支不是坏实践，能更早处理冲突，适合敏捷开发。
