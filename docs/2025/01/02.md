## 2. 函数 return 什么时候需要 `std::move`

简而言之，不会触发 RVO 的时候。

```cpp
std::vector<int> f() {
    std::vector<std::vector<int>> s = {{1, 2, 3}};
    return s[0];  // 不会触发 RVO，需要 std::move
}
```
