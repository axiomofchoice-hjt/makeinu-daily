## 2. gtest 只能 mock virtual 成员函数

不是很好用。

`extern "C"` 和系统调用可以用库插桩 mock。C++ 由于 name mangling 难以 mock。

## 3. `std::string` 在比较相等前先比较长度有没有必要

```cpp
if (a.size() == b.size() && a == b) {
  // ...
}
```

没有必要，标准库一般都会考虑到。
