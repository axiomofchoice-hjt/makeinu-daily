## 3. 群友同事写的 new + free 代码

```cpp

free(t);
```

## 4. 群友同事手写排序，比较运算不是偏序

`comp(A, B) = (A.pessi - B.optim > 0)` 前一个的悲观值和后一个的乐观值进行比较。这哥们发现了运行结果不对，但他说：如果某个 task 真的优势大，多来几轮，他就能排到最后一个了。

后来测试的出来不对，哥们还是说这个复合设计。
