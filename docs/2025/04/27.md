## 3. C++ 初始化方式

喜欢我 C++ 的初始化吗：

![img](/img/2025-04-27-0.webp)

[图片来源](https://www.zhihu.com/question/497428726/answer/2213203090)

其实可以归纳为 <https://www.zhihu.com/question/403578855/answer/1842778970> 所说：

> 1. 可以用 `{}` 初始化，总是用 `{}` 初始化。
> 2. 不能用 `{}` 初始化，用 `=` 初始化。

## 4. `std::vector<int[2]>` 可以编译

但是很没用，无法增加元素（`push_back` / `emplace_back`）。

不过要到 c++26 才可以编译：<https://cplusplus.github.io/LWG/issue3436>。

## 5. `std::array` 不指定元素个数

C++17 有了 CTAD，可以省略模板参数。

```cpp
std::array a = {1, 2, 3};
```
