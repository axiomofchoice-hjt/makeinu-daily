## 1. GCC 不能在类里面特化模板

```cpp
struct A {
    template <bool tag>
    void bar();

    template <>
    void bar<true>() {}  // error: explicit specialization in non-namespace scope 'struct A'

};
```

这是 GCC 未实现的 feature。

<https://gcc.gnu.org/bugzilla/show_bug.cgi?id=85282>
