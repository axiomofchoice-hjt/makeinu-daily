## 2. copy on write 是什么

就是多个使用者可以读相同的资源，如果要修改就拷贝一份出去再修改。

linux fork 后的内存就是 COW 的，子进程修改父进程的内存页，会触发缺页异常，然后重新挂物理地址，但是使用的是同一个虚拟地址。
