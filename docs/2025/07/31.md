## 1. `-Weverything`

如果你觉得代码会触发某些警告但是不知道 Clang 有没有支持的话，可以用 `-Weverything`。

<https://clang.llvm.org/docs/UsersManual.html#diagnostics-enable-everything>

## 2. 死代码需要清理吗

例如：

```cpp
if (condition) {
    return res;
    break;  // 永远不会执行
}
```

要清理。没啥大毛病，只是 error-prone，就是反向推测你可能想实现的是别的逻辑，但是写错了。
