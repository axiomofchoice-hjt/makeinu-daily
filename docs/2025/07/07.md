## 2. 变量名包含 `__LINE__` 的宏

直接这么写是不对的：

```cpp
#define macro(x) int x_##__LINE__ = 0

int main() {
    macro(x);  // int x____LINE__ = 0;
}
```

要给这 x 和 `__LINE__` 套两个宏再拼接：

```cpp
#define CONCAT1(x, line) x##line
#define CONCAT(x, line) CONCAT1(x, line)
#define macro(x) int CONCAT(x, __LINE__) = 0

int main() {
    macro(x);  // int x6 = 0;
}
```
