## 3. 错误代码：类的 set 函数写成 const，成员变量标为 mutable

神人。这么写 const 直接失去意义了，和众所周知的语义完全违背。

如果这个成员变量改变，但是外部看来这个对象没变，那就可以用 mutable。例子是 mutex、内部缓存。
